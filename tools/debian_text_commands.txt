# Rules for this list:
#   - Nothing whose answer depends on the machine: no listings, no users, no network,
#     no processes. Paths either do not exist anywhere (names with "nonexistent",
#     "missing", "nosuch", "nope") or exist on every Debian (/etc, /tmp, /usr,
#     /etc/passwd as a NAME only, never its contents).
#   - Nothing that waits for input, needs a terminal, or changes files.
#   - No command of the 43 test commands; the builder drops any that slips in, and any
#     answer sharing three lines in a row with a test answer.
#   - No syntax errors and no job control: bash words those differently in a login
#     shell and under `bash -c`, and only the simple `-bash: ` prefix is measured.
#   - Do not delete or reorder lines carelessly: the held-back 10% is chosen by a hash of
#     the command text, so it follows the command, not its line number.
